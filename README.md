# DX11-Learning-Framework
A simple DirectX 11 learning framework that implements fundamental rendering pipeline management and basic geometry rendering. It includes premade model generation, complex model handling, and scene management. The framework incorporates a Phong lighting model with multiple light sources, fog effects, and a mirror application. Additionally, it supports normal mapping, height-map terrains, and water instancing for realistic rendering.
